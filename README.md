# Data Science Portfolio: Anker Innovations Cross-border E-commerce Analysis
This is a data visualization and exploratory analysis project for Anker Innovations, a leading cross-border e-commerce brand.

## Project Overview
This project analyses the revenue performance of four major product lines of Anker from 2021 to 2024, using grouped bar chart and stacked bar chart to show growth trend and revenue composition.

## Files in this repository
- `ankr_analysis.ipynb`: Main Python analysis notebook
- `requirements.txt`: Required Python libraries
- `grouped_bar_anker.png`: Grouped bar chart for category comparison
- `stacked_bar_anker.png`: Stacked bar chart for revenue composition

## Visualization & Findings
1. Charging accessories are the main income source of Anker.
2. Audio and smart home categories have rapid growth, reflecting successful brand expansion.
3. The overall business maintains stable upward trend in global market.

## Tools
Python, Pandas, Matplotlib
